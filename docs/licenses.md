# License audit

Last checked on 2026-10-15 against the workspace `Cargo.lock`, the link lines of the gallery release build (`otool -L` and `ldd`), and the published crate files. The licenses of the Linux system libraries come from their Ubuntu 22.04 packages. Do the audit again before each release and for each change to the dependency rule (see [releasing.md](releasing.md) and [architecture.md](architecture.md)).

## Project license

ChoscorUI has a dual license, `MIT OR Apache-2.0` ([`LICENSE-MIT`](../LICENSE-MIT) and [`LICENSE-APACHE`](../LICENSE-APACHE)). The user selects one license. The workspace sets `license = "MIT OR Apache-2.0"` in `[workspace.package]`. Each crate, including the gallery and the benchmark, uses `license.workspace = true`.

The workspace crates are first-party. `cargo tree --workspace -e normal --prefix none | sort -u` must show only the workspace crates and the rows above. The gallery depends only on the `choscorui` path crate.

## Notices in the published crates

A release publishes the crates to crates.io and attaches no binaries. Each published crate contains `LICENSE-MIT` and `LICENSE-APACHE` as links to the files at the repository root. `cargo package` copies the content of the linked files.

[`crates/choscorui-core/THIRD-PARTY-NOTICES.txt`](../crates/choscorui-core/THIRD-PARTY-NOTICES.txt) contains the Lucide and Feather notices. The Lucide icon shapes are in that crate, so the notices go with each copy.

## Notices for application binaries

An application binary contains code from `std` and `unicode-segmentation` under the MIT license. It also contains the Lucide icon shapes. If you distribute a binary, include the MIT notices of these components and the notices in `THIRD-PARTY-NOTICES.txt`. Neither MIT component has an Apache-2.0 notice file.

## Linked system libraries (macOS)

The release binaries link only these libraries (`otool -L target/release/choscorui-gallery`):

- **Frameworks:** AppKit, Foundation, CoreFoundation, CoreGraphics, CoreText, ImageIO, Metal, QuartzCore, and UserNotifications.
- **Libraries:** `libobjc` and `libSystem`.

macOS supplies these libraries, and they load dynamically. The Xcode and macOS SDK license agreements apply to them. ChoscorUI does not distribute them.
