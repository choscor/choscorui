# License audit

Last checked on 2026-10-12 against the workspace `Cargo.lock`, the link line of the release binaries (`otool -L`), and the contents of the release archive. Do the audit again before each release and for each change to the dependency rule (see [releasing.md](releasing.md) and [architecture.md](architecture.md)).

## Project license

ChoscorUI has a dual license, `MIT OR Apache-2.0` ([`LICENSE-MIT`](../LICENSE-MIT) and [`LICENSE-APACHE`](../LICENSE-APACHE)). The user selects one license. The workspace sets `license = "MIT OR Apache-2.0"` in `[workspace.package]`. Each crate, including the gallery and the benchmark, uses `license.workspace = true`.

## Rust crates in the build graph

| Crate | Version | License | Used by | Notes |
| --- | --- | --- | --- | --- |
| `unicode-segmentation` | 1.13.3 | MIT OR Apache-2.0 | `choscorui-core` | The only third-party crate. It has no dependencies. |
| Rust standard library (`std`, `core`, `alloc`) | toolchain | MIT OR Apache-2.0 | all binaries | Statically linked into release binaries |

The workspace crates are first-party. `cargo tree --workspace -e normal --prefix none | sort -u` must show only the workspace crates and the rows above. The gallery depends only on the `choscorui` path crate.

## Notices in the release archive

A release binary contains code from `std` and `unicode-segmentation` under the MIT license. The MIT license requires that its copyright and permission notice go with each copy. Neither component has an Apache-2.0 notice file.

[`scripts/macos/third-party-notices.txt`](../scripts/macos/third-party-notices.txt) contains these notices. `scripts/macos/package.sh` copies it into each archive as `THIRD-PARTY-NOTICES.txt`, together with `LICENSE-MIT` and `LICENSE-APACHE`. The source repository does not contain the code of these components, so the repository root has no notice file.

## Linked system libraries (macOS)

The release binaries link only these libraries (`otool -L dist/choscorui-*/…/Contents/MacOS/*`):

- **Frameworks:** AppKit, Foundation, CoreFoundation, CoreGraphics, CoreText, ImageIO, and UserNotifications.
- **Libraries:** `libobjc` and `libSystem`.

macOS supplies these libraries, and they load dynamically. The Xcode and macOS SDK license agreements apply to them. ChoscorUI does not distribute them.
